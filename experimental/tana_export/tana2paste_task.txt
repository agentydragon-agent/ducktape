Complete tana2paste.py.

Analogously to tana2md.py, read a Tana export file, but render it as Tana Paste format, not ~Markdown.
Use https://tana.inc/docs/tana-paste as a reference of the Tana Paste format.
Fine to render the Tana JSON dump as one big block, not split into individual files.

There's a Tana export in ~/downloads/tana-export-2025-05-12.json. Use it to iterate/test.

Do not rewrite the whole thing from scratch. Build up some kind of shared representation/library for loading and such.
In a separate format-independent file. Also write tests as appropriate, especially with smaller-size pieces of the input JSON dump.

Note that the JSON dump is quite huge. Be careful printing from it. Examine carefully how big anything you're about to print is.
