KEY TECHNICAL INSIGHTS
=======================

1. Hybrid VPS + Proxmox introduces 10-15 minute convergence window:
   - KubeSpan WireGuard mesh negotiation
   - Cilium IPAM mode "kubernetes" pod CIDR advertisement
   - Node ReadinessGate requires all CNI + API + kubelet components ready

2. Kyverno webhook readiness sequence is non-trivial:
   - Pod Readiness ≠ Webhook Readiness
   - VWC must be created by webhook-controller AFTER pod starts
   - Takes ~10-20 seconds from pod Running to webhook callable
   - Explicit dependsOn declarations essential to prevent races

3. VXLAN + KubeSpan layering:
   - VXLAN for pod overlay (UDP 4789)
   - KubeSpan for node mesh (UDP 51820 WireGuard)
   - Creates 3-layer tunnel: pod traffic → VXLAN → WireGuard
